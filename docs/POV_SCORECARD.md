# Scorecard da prova de valor paga

## Baseline

Antes do uso do MeetMind, registrar por quatro semanas: reuniões processadas, tempo médio de
leitura, ações identificadas, ações executadas, falhas de acompanhamento e custo humano.

## Medição

| Métrica | Baseline | Meta | Resultado | Evidência |
|---|---:|---:|---:|---|
| Redução do tempo de leitura |  | >= 50% |  |  |
| Achados com segmentos válidos |  | 100% |  |  |
| Afirmações sem suporte |  | < 1% |  |  |
| Próximos passos úteis |  | >= 80% |  |  |
| Usuários ativos semanais |  | >= 70% dos convidados |  |  |
| Custo médio por reunião |  | limite contratado |  |  |
| Incidentes críticos |  | 0 |  |  |

- Período e volume autorizados:

- Próxima etapa aprovada:
